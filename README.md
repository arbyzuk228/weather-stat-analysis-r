# Функціонал
- **Очищення даних:** фільтрація часових меж, видалення колонок із часткою пропусків понад 80%.
- **Дослідницький аналіз (EDA):** побудова гістограм розподілу температури, опадів, швидкості вітру та тиску.
- **Кластеризація (K-means):** визначення оптимальної кількості кластерів методом ліктя (k=3). Алгоритм розділяє дані на три сезони: холодний, перехідний (весна/осінь) та теплий.
- **Кореляційний аналіз:** побудова матриці кореляцій (виявлено сильний зв'язок між температурними показниками та обернений зв'язок між тиском і опадами).
- **Регресійний аналіз:** побудова лінійної моделі `tavg ~ tmin + tmax + prcp + wspd + pres`, оцінка її якості на тестовій вибірці (2024 рік) та прогнозування на 2025 рік.

## Обмеження та плани на майбутнє (Магістратура)
Поточна версія коду є базовою. У магістерській роботі планується вдосконалити методику:
1. **Робота з пропусками:** Поточна реалізація використовує метод na.omit() (повне видалення рядків) та звужує аналіз до 2021–2024 років. Це призводить до втрати даних, зокрема всього 2020 року. У магістерській роботі планується застосувати методи імпутації (заповнення пропусків на основі наявних даних, наприклад, методом KNN або лінійної інтерполяції) для відновлення даних 2020 року та збереження повноти вибірки.
2. **Мультиколінеарність:** висока кореляція (понад 0.9) між предикторами `tmin` та `tmax` створює мультиколінеарність у регресійній моделі. Планується перевірка VIF-факторів та виключення надлишкових змінних для підвищення стабільності моделі.
